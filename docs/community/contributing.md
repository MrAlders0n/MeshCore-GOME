# Contributing to OttawaMesh.ca

If you’d like to contribute or help improve the site, you have three options:

- **Reach out to users who have the @Knowledge Curator tag on Discord** for quick questions or discussion  
- **Follow the steps below** to [request changes via GitHub](#how-to-request-changes-via-github)  
- **Contribute to our user driven [Bookstack Wiki](#contributing-to-community-driven-wiki)**

---

## How to Request Changes via Github

If you want to add a new repeater, update deployment details, or fix documentation, the easiest way is to open a **GitHub Issue**.

You do not need to know Git, GitHub, or how to edit the website. Just follow the steps below.

---

### 1. Go to the Issues page

Visit the Ottawa Mesh GitHub repository and click **Issues**.

Link: <https://github.com/MrAlders0n/MeshCore-GOME/issues>

---

### 2. Click "New Issue"

Choose the template that matches what you want to do:

- **Repeater Deployment Update**
- **New Documentation Request**
- **Documentation Correction**
- **Incorrect Information**

---

### 3. Fill out the form

Provide as much detail as possible.

---

### 4. Submit the issue

A maintainer will:

1. Review the request  
2. Make the change  
3. Close the issue when complete  

If we need more information, we’ll comment on the ticket.

---

### 5. Optional — Advanced Contributions

If you know GitHub and want to edit the markdown files directly:

1. Fork the repo  
2. Edit the relevant file in `docs/`  
3. Open a pull request  

---

## Contributing to community-driven Wiki

We also have a community driven Bookstack Wiki that makes it easier to register and collaborate. Here you can showcase your repeater, add tutorials on specific builds, etc. Information found here may also be transferred to the main site.

You can visit this Wiki at [https://meshcore.wiki.gd/](https://meshcore.wiki.gd/)

If you want to contribute to the Wiki, please register for an account here: [https://meshcore.wiki.gd/register](https://meshcore.wiki.gd/register)

---
