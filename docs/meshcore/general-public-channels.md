# Public Channels Directory

Public is the default unencrypted channel, this is where new users land, and sometimes the default conversations, however #ottawa is sometimes favoured (at least before the traffic was scoped). No bots are allowed here. The only bot there is ottobot but only for welcoming new usernames with our mesh website for procedures.

## Hashtag Channels

MeshCore hashtag channels are public topic-based groups that start with a "#" symbol, allowing users to join and communicate on specific subjects. These channels are not encrypted, so anyone can read the messages. You can join them by entering the channel name or scanning a QR code in the MeshCore app.
